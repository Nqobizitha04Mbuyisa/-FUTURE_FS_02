# Mini CRM — Backend (Spring Boot)

REST API backend for the Mini CRM Lead Management System.

The backend powers:

- JWT authentication
- Lead management APIs
- Dashboard statistics
- Public contact submissions
- Admin authorization
- PostgreSQL database persistence

See the root [README](../README.md) for full-stack setup and live demo information.
